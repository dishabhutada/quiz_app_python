# quiz_app_python
Simple quiz app built using Python CLI

🧠 Python Quiz App

This is a simple command-line quiz application built using Python.  
The user answers multiple-choice questions and earns points for correct answers.


📌 Features

- Multiple-choice questions
- Score tracking after each question
- No negative marking
- Built using only Python — beginner-friendly



🚀 How to Run

1. Make sure Python is installed on your system  
2. Download the `quiz_app.py` file  
3. Open terminal or command prompt  
4. Run the file with:


python quiz_app.py
